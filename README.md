# 窮鬼生活｜問題與功能回報

這裡是「窮鬼生活」的公開回報區，不包含應用程式原始碼。

- [開啟網站](https://thuglife.kobebryant6082.workers.dev)
- [回報問題或提出功能建議](https://github.com/supaquantboys/thuglife-feedback/issues/new/choose)

> ⚠️ **發現資安問題請勿公開回報。** 請改用[私下回報資安問題](https://github.com/supaquantboys/thuglife-feedback/security/advisories/new)，詳見下方「資安問題請勿公開回報」與 [SECURITY.md](SECURITY.md)。

開單需要 GitHub 帳號。請先搜尋既有 Issues，避免重複回報。

## 回報方式

選擇「問題回報」或「功能請求」表單，填寫描述與重現步驟；截圖請先遮蔽個人資料。

此儲存庫與所有 Issues 皆為公開。請勿貼上密碼、驗證碼、存取金鑰、登入 token、私人聯絡資料或完整個人資料。

維護者會在 Issue 中回覆、釐清與更新處理進度；實作與程式碼審查於私人儲存庫進行。

## 資安問題請勿公開回報

如果你發現的是資安問題（例如可以繞過限制、存取不該看到的資料、冒用他人帳號、濫用投票或點數等漏洞），**請不要開公開 Issue**，也不要在任何公開 Issue 或留言中描述做法、步驟或技術細節。

請改用 GitHub 的私下回報功能：

1. 到此儲存庫的 **Security** 分頁
2. 點選 **Report a vulnerability**
3. 填寫問題內容後送出，只有維護者看得到

直接連結：<https://github.com/supaquantboys/thuglife-feedback/security/advisories/new>

完整說明請見 [SECURITY.md](SECURITY.md)。若不確定是不是資安問題，請先當作資安問題私下回報。
