## 回報方式

選擇「問題回報」或「功能請求」表單，填寫描述與重現步驟；截圖請先遮蔽個人資料。

此儲存庫與所有 Issues 皆為公開。請勿貼上密碼、驗證碼、存取金鑰、登入 token、私人聯絡資料或完整個人資料。

維護者會在 Issue 中回覆、釐清與更新處理進度；實作與程式碼審查於私人儲存庫進行。
